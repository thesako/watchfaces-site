# watchfaces.thesako.com

The site for the thesako watch faces, served by GitHub Pages.

Edit the content in `build.py`, then run `python3 build.py` and commit the generated HTML. When a face goes live on the Connect IQ Store, add its store link to `STORE` in `build.py`.

Watch-face screenshots are in `assets/faces/`. The Saira font (`assets/fonts/`) is used under the SIL Open Font License.
